# LineTax
It contains the code and details of my project LineTax
LineTax is a line following robot that works based on the principle of IR sensors. It follows a line of black tape as its path and thats pretty much it.

# Components Used:
1 Arduino Uno
1 Arduino Uno Motor Driver Shield L293D
4 DC Motors
2 IR Sensors
2 Li-ion Batteries
1 Switch
1 Custom Designed Chassis of your choice
